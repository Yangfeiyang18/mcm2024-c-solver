# 实验结论

## 第 1 轮：问题1完整模型

- 本轮目的：求解2024—2030年两种超额产量处理情形下的最优种植方案，并检查官方结果表和全部约束。
- 使用模型：带面积、适宜性、水浇地模式、轮作、豆类覆盖、最小种植面积和作物分散度约束的混合整数线性规划（MILP）。
- 情形一：超出预期销售量的部分滞销浪费。
- 情形二：超出预期销售量的部分按2023年销售价格的50%出售。

### 核心结果

| 指标 | 滞销浪费 | 超额部分半价出售 | 变化 |
|---|---:|---:|---:|
| 2024—2030累计利润 | 4075.77万元 | 5838.10万元 | +1762.32万元（+43.24%） |
| 七年总产量 | 884.76万斤 | 1495.71万斤 | +69.05% |
| 超出预期销量的产量占比 | 2.17% | 53.04% | +50.87个百分点 |
| 约束违反数 | 0 | 0 | 均通过 |
| 求解状态 | 达到时间上限，最优性差距1.07% | 在1%容差下最优，差距0.93% | 两者均为高质量可行解 |

### 审查结论

1. 两个工作簿均包含2024—2030七张年度表，合计14张，工作表范围和官方模板一致，未发现公式错误或破坏模板结构的问题。
2. 利润独立重算与求解器目标值的差异均小于0.03元，数值核对通过。
3. 面积、适宜性、水浇地稻菜模式、相邻年份重茬、2023—2024衔接、智慧大棚连续季、三年豆类覆盖、最小面积和每作物最多七块地等检查均为0违规。
4. 半价方案的53.04%不是“浪费率”，应称为“超额产量占比”或“半价销售产量占比”。这些产量虽然超过正常销量，但已经按半价计入收入。
5. 半价方案的大量超产具有模型内经济原因，不是明显程序错误。以黄瓜为例，其半价销售后的亩均收入仍明显高于亩均成本，因此模型会主动扩大黄瓜生产。黄瓜贡献约524.42万斤超额产量，占该方案全部超额产量约66.1%，是结果变化的主要来源。
6. 半价方案利润呈明显隔年高低波动：2024、2026、2028、2030年较高，2025、2027、2029年较低。这主要与高利润作物不能连续重茬有关，论文中需要说明，不应只报告七年合计值。

### 必须修正

- 官方结果表中部分亩数保留6位小数，而模板列宽较窄，显示时会出现数字被遮挡或难以阅读。建议不改变底层数值，只把种植面积单元格统一设置为显示2位小数；如果直接四舍五入底层数值，必须重新运行约束审计。
- 论文和交接材料统一把4075.77万元、5838.10万元写成“2024—2030七年累计利润”，不得误写成年利润。
- 半价情形统一使用“超额产量占比53.04%”，不得表述为“53.04%的产量被浪费”。

### 建议补充但不阻塞第二问

- 输出一张年度利润对比图，展示半价方案的隔年波动。
- 对黄瓜单独列出面积、产量、正常价销量、半价销量和利润贡献，防止论文只用一句“黄瓜大量超产”而缺少数字证据。
- 在模型局限中说明：题面规定超额部分都能按半价出售，未再设置半价市场容量，因此53.04%的超额产量是题设口径下的数学结果，现实中可能偏乐观。

### 本轮结论

问题1结果总体通过，可以开始问题2；代码手只需修正Excel显示格式和结果用词，不必重跑问题1优化。滞销浪费方案尚未证明严格最优，因此论文应称为“最优性差距1.07%的高质量可行方案”，不能写成“精确最优解”。
