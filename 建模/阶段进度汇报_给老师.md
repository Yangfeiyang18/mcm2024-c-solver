# 2024年C题阶段进度汇报

## 一、口头汇报稿

我们目前已经完成了2024年C题的问题分析、数据整理和模型池设计，并完成了问题1的正式求解。

这道题的总体目标，是为乡村制定2024—2030年的农作物种植方案。我们把三问理解为逐步递进的关系：问题1在各项数据保持稳定的情况下求确定性最优方案；问题2进一步考虑销量、亩产量、成本和价格的不确定性，寻找收益和风险之间较均衡的方案；问题3再考虑作物间替代、互补以及各参数之间的相关关系，检验并改进问题2方案。

数据方面，我们已经整理了54块地和41种作物的信息，完成了合并单元格填充、文本清洗、价格区间拆分、2023年预期销量计算、作物适宜性映射和官方结果模板映射。智慧大棚第一季参数按附件2说明直接沿用普通大棚第一季参数，不属于读取错误或主观补值。

模型方面，问题1采用混合整数线性规划。目标是最大化2024—2030年累计利润，即销售收入减去种植成本；同时考虑土地面积、作物适宜性、水浇地种植模式、重茬限制、三年豆类覆盖以及便于管理等条件。问题1分别求解了超额产量浪费和超额产量半价销售两种情形。

目前结果为：滞销浪费情形七年累计利润约4075.77万元，超额产量占比2.17%，该方案的最优性差距为1.07%；半价销售情形七年累计利润约5838.10万元，超额产量占比53.04%，在1%的求解容差下达到最优。半价方案比浪费方案增加利润约1762.32万元，即43.24%。两种方案经过独立检查，面积、适宜性、轮作、豆类覆盖和管理条件均没有发现违规。

半价方案出现大量超额生产，主要是因为黄瓜等作物即使按半价销售，亩均收入仍高于种植成本，因此模型会主动扩大生产。这是题目允许超额产品均按半价出售所产生的结果，但现实中可能偏乐观，我们准备在论文中明确说明这个局限。

问题2已经确定采用“均值模型作为基线、SAA-CVaR随机优化作为主模型”的方案。我们会生成优化情景和独立测试情景，比较平均利润和较差情景下的利润，避免只追求平均收益。问题3计划分成两层：先只加入产量、价格、需求和成本的相关变化，再加入作物之间的替代和互补关系，从而区分两类因素各自造成的影响。问题2与问题3方案会在同一批测试情景上比较。

下一步工作是完成问题1图表和文字解释，同时开始问题2的情景生成、风险模型求解和样本外检验；问题2的程序和评价方法固定后，再正式运行问题3。

## 四、建议向老师请教的问题

### 1. “便于耕种管理”应该怎样量化

题目要求兼顾管理便利，但没有给出明确数值。我们目前设置为：露天地和水浇地每次种植面积至少5亩，大棚至少0.3亩，同一种作物同一年同一季最多分布在7块地。

可请教老师：这种做成硬约束的方式是否合理？是否更适合把“地块过于分散”作为惩罚项，与利润一起进行多目标优化？

### 2. 预期销售量应按什么层级汇总

我们目前根据题目“各季”的表述，按“作物—季次”计算2023年预期销售量。另一种做法是将同一种作物全年合并成一个销售上限，这会明显改变利润。

可请教老师：主模型按作物—季次设置销售上限是否更符合题意？是否有必要把全年汇总作为敏感性分析？

### 3. 三年内种植一次豆类应怎样理解

我们用“连续三年累计豆类种植面积不少于该地块面积”表达这一要求，因此允许分几年、分部分面积完成。

可请教老师：是否应该更严格地要求三年内至少有一个季次整块地种植豆类？哪种解释更符合竞赛论文的常见处理？

### 4. 半价销售是否需要增加现实限制

按照题面，所有超额产量都能按原价50%出售，因此模型得到53.04%的超额产量占比，并高度集中于黄瓜等半价销售仍然盈利的作物。

可请教老师：主结果是否应严格按题面保留这一结果，只在局限中解释；还是应增加“半价市场容量有限”的敏感性情景，使建议更符合现实？

### 5. 问题3缺少真实相关系数和弹性数据时如何把握复杂度

附件无法直接估计作物间替代、互补强度和参数相关系数。我们准备采用弱、中、强情景并做敏感性分析，不把模拟参数写成真实观测值。

可请教老师：这种情景模拟是否足以回答问题3？是否需要额外查文献确定少量典型作物关系，还是以作物类群进行方向性分析更稳妥？

## 五、优先请教顺序

如果老师时间有限，建议优先询问：

1. 预期销量按“作物—季次”还是按“作物全年”汇总；
2. “三年种一次豆类”的具体建模口径；
3. 管理便利应采用硬约束还是多目标惩罚；
4. 半价销售导致大量超产时是否只解释局限，还是增加现实容量敏感性。

这些问题都会实质性改变问题1结果，最好在问题2正式运行前统一口径。
