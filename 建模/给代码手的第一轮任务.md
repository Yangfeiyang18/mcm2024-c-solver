## 5. 问题 1：第一轮模型任务

### 5.1 目标函数

#### 情景A：超产浪费

```text
maximize sum(normal_price_revenue) - sum(planting_cost)
```

超出需求上限的产量收入为0，但种植成本仍计入。

#### 情景B：超产半价

```text
maximize normal_price_revenue
       + 0.5 * price * surplus_sales
       - planting_cost
```

两情景必须使用同一套数据、适宜性和农业约束。

### 5.2 要跑的模型

1. `Q1_baseline`：不加最小面积和最大地块数的简化模型，用于对账。
2. `Q1_full_waste`：完整MILP，超产浪费。
3. `Q1_full_discount`：完整MILP，超产半价。

### 5.3 必须包含的约束

- 地块-季次面积上限。
- 作物-地块-季次适宜性。
- 水浇地“水稻/两季蔬菜”二选一。
- 水浇地第二季的大白菜、白萝卜、红萝卜三选一。
- 普通大棚和智慧大棚季次规则。
- 重茬约束，包括2023-2024和智慧大棚年内/跨年连续季。
- 任意连续三年的豆类覆盖，首窗口使用2023年数据。
- `min_area*y <= x <= area*y`。
- 每作物每季最大地块数。
- 销量上限和超产分段收入。

### 5.4 求解要求

- 优先使用可获得的MILP求解器；若有Gurobi/CPLEX则可使用，否则用HiGHS/SCIP/CBC等可复现求解器。
- 第一轮问题1时间上限10分钟，目标 `MIP gap <= 1%`。
- 若超时，交当前最佳可行解、下/上界、gap和日志，不可只写“没跑完”。

## 6. 问题 2：第一轮模型任务

### 6.1 情景生成规则

第一轮问题2中，各作物、参数和年份的扰动先视为独立，相关性留给问题3。

| 参数 | 第一轮分布/递推规则 |
|---|---|
| 小麦、玉米销量 | 每年增长率 `Uniform(5%,10%)`，按年复利递推 |
| 其他作物销量 | 每年 `D_2023*(1+eps)`，`eps~Uniform(-5%,5%)`，不复利累积 |
| 亩产量 | 每年 `Y_2023*(1+eps)`，`eps~Uniform(-10%,10%)` |
| 种植成本 | 年增长率 `Triangular(4%,5%,6%)`，复利递推 |
| 粮食价格 | 以2023价格中点为基准，每年小幅扰动 `Uniform(-1%,1%)`，不复利累积；用于把“基本稳定”量化，并为问题3保留可相关的非零波动 |
| 蔬菜价格 | 年增长率 `Triangular(4%,5%,6%)`，复利递推 |
| 普通食用菌价格 | 年下降率 `Uniform(1%,5%)`，复利递推 |
| 羊肚菌价格 | 每年固定下降5%，复利递推 |

成本和蔬菜价格的三角分布、粮食价格的±1%稳定带都是第一轮模拟假设，必须写入配置和结果说明，不得写成题目原始条件。羊肚菌价格严格按每年下降5%处理，没有随机波动。

### 6.2 数据划分/实验设计

这是优化问题，不使用传统“训练集/测试集”，而使用：

- **优化情景集**：100个情景，用于求解SAA-CVaR模型。
- **样本外测试情景集**：2000个独立情景，只用于评估和选择方案，不进入求解。
- **收敛检验**：对最终选中的风险权重，另用50、200个优化情景重跑或至少跑简化版，检查种植结构是否稳定。

### 6.3 要跑的模型

1. `Q2_mean_value`：用均值/中点参数的确定性MILP。
2. `Q2_SAA_lambda_0`：只最大化情景平均利润。
3. `Q2_SAA_lambda_025`：期望利润-CVaR折中。
4. `Q2_SAA_lambda_050`：更偏向尾部风险控制。

统一使用 `alpha=0.90`。如目标函数中利润与CVaR量纲使 `lambda` 含义不稳定，先用2023基准利润或均值模型利润对两项做归一化，并在日志中记录公式。

### 6.4 求解要求

- 每个SAA模型第一轮时间上限30分钟，目标 `MIP gap <= 3%`。
- 如规模过大，先用50个优化情景跑通，但不得取消样本外测试。
- 所有候选方案必须在同一2000个测试情景上评估。

## 7. 问题 3：第一轮试验任务

问题3在问题2模型、样本外评估程序和折中方案尚未锁定前不得抢跑最终版。

### 7.1 作物类群

第一轮可先按名称和作物类型构造以下类群，并把分组放在可编辑配置文件中：

- 主要粮食替代组：小麦、玉米。
- 豆类组：黄豆、黑豆、红豆、绿豆、爬豆、豇豆、刀豆、芸豆。
- 叶菜组：菠菜、油麦菜、小青菜、生菜、空心菜、黄心菜、芹菜等。
- 茄果组：西红柿、茄子、青椒、黄瓜、辣椒等。
- 甘蓝/根茎组：菜花、包菜、大白菜、白萝卜、红萝卜、土豆等。
- 食用菌组：榆黄菇、香菇、白灵菇、羊肚菌。

这是模拟分组，不是附件中已给的市场分组。

### 7.2 相关情景生成

使用潜在因子而不是任意手写大型协方差矩阵：

- `M_group`：作物类群市场因子，同时正向影响类群内需求和价格，表示需求整体变旺；不要写成“需求曲线移动为负”。
- `C_input`：投入成本因子，影响各作物成本并部分传导到价格。
- `W_group`：类群气候因子，正向影响类群内亩产量，并负向影响存在随机波动的价格，用于模拟丰产时价格承压。
- `E_idio`：作物自身独立扰动。

羊肚菌价格因严格固定为每年下降5%，不接受任何价格因子载荷；粮食价格使用问题2的±1%稳定带，因此可以与亩产量形成弱负相关。

第一轮只跑弱和中两档公共因子权重，强相关留给下一轮：

| 档位 | 公共因子标准化权重 | 个体扰动标准化权重 |
|---|---:|---:|
| 弱相关 | 0.30 | `sqrt(1-0.30^2)` |
| 中相关 | 0.60 | `sqrt(1-0.60^2)` |

分位数映射必须按以下顺序实现：合成扰动标准化得到 `z`，计算 `u=Phi(z)`，再用问题2目标分布的逆分布函数 `F^{-1}(u)` 得到参数值。不得直接截断或线性缩放。程序须检查并输出各参数的经验均值、分位数、范围和经验相关系数；公共因子权重不等于最终相关系数。

### 7.3 两层正式试验

1. `Q3_A_correlation_only`：保持问题2边际分布，只加入相关因子，不加入交叉价格弹性。
2. `Q3_B_correlation_elasticity`：在同一相关机制上正式加入替代和互补关系，作为问题3最终候选方案。

替代和互补是题目明确要求，Q3-B不得因时间不足被删去。Q3-A用于拆分影响来源，不代替Q3-B。

#### 替代/互补参数

第一轮交叉价格弹性只设小强度：

- 明确替代组内：`epsilon[i,j]=+0.15`。
- 互补对：主设定暂用 `epsilon[i,j]=-0.10`。甲、乙须在正式运行前确认至少一组有现实解释的互补关系；能找到文献的标为“文献支持”，只能依据经验设置的标为“情景假设”。不得随意配对，也不得把全部互补弹性置0后声称已经考虑互补性。
- 其他作物对：0。
- 调整后需求截断在 `0.5*base_demand` 至 `1.5*base_demand`。
- Q3-B至少做弹性为0、小强度和中强度三档的单因素敏感性分析；0档与Q3-A一致，用于核对程序。

### 7.4 模型和比较

## 11. 自动验收检查

### 11.1 解的可行性

对每个导出方案，用独立的校验函数检查，不要只依赖求解器返回状态：

- 面积非负。
- 各地块季次面积不超上限。
- 不存在不适宜作物。
- 水浇地模式合法。
- 重茬、三年豆类、最小面积和最大地块数无违反。
- 总产量等于面积乘亩产量的汇总。
- 正常销量不超过产量和预期销量。
- 利润表可从产销表和成本表重新汇总对上。

### 11.2 官方模板
