# 2024 年 C 题模型池

> 主责角色：乙（建模手）  
> 协作角色：丙（代码手，确认可实现性）  
> 目的：为每一问准备基线、主模型和备选模型，明确比较指标、检验和第一轮实验顺序。

## 1. 共同模型骨架

### 1.1 核心决策

定义：

- `x[t,l,s,c] >= 0`：年份 `t`、地块 `l`、季次 `s`种植作物 `c` 的面积。
- `y[t,l,s,c] in {0,1}`：该作物是否进入该地块。
- `r[t,l] in {0,1}`：水浇地当年是否选择单季水稻模式。

其中 `x` 是最终填入官方模板的结果，`y`和`r`只用于约束种植结构。

### 1.2 生产与销售

当季作物产量：

```text
Q[t,c,s] = sum over l of yield[t,c,land_type(l),s] * x[t,l,s,c]
```

引入正常销量 `u[t,c,s]` 和超额产量 `v[t,c,s]`：

```text
0 <= u[t,c,s] <= demand[t,c,s]
u[t,c,s] <= Q[t,c,s]
v[t,c,s] = Q[t,c,s] - u[t,c,s]
```

由于正常价格高于超额价格，最大化利润时会自动使 `u=min(Q,demand)`。

### 1.3 基础利润

情景1（超产浪费）：

```text
profit = sum(p * u) - sum(cost * x)
```

情景2（超产半价）：

```text
profit = sum(p * u + 0.5 * p * v) - sum(cost * x)
```

如同一作物在同一季次来自多种地块类型且价格不同，正式模型应按“作物-季次-地类”设销量辅助变量，同时对同作物-季次共享总需求上限，避免用平均价格造成收入偏差。

### 1.4 所有模型共用的硬约束

1. **面积约束**：每个地块-季次的作物面积和不超过可用面积。
2. **适宜性约束**：不符合地块类型或季次要求的 `x` 固定为0，或根本不建变量。
3. **水浇地模式**：每年只能选择一季水稻或两季蔬菜；第二季只能在大白菜、白萝卜和红萝卜中选一种。
4. **普通大棚**：第一季为允许的蔬菜，第二季只能为食用菌。
5. **智慧大棚**：两季都只能种允许的蔬菜。
6. **重茬约束**：同一作物在同一地块的连续可种时段不能同时出现；包括2023-2024、年内两季和跨年第二季-第一季。
7. **三年豆类约束**：任意连续三年中，各地块的豆类累计面积不小于该地块面积；首个2023-2025窗口必须纳入2023年数据。
8. **种植启用约束**：`min_area[l] * y <= x <= area[l] * y`。
9. **分散度约束**：某作物每年每季启用的地块数不超过 `K[c,s]`。
10. **非负和取值域**：面积、销量、产量均非负，模式和启用变量为0-1。

## 2. 问题 1 模型池

### 2.1 基线模型：连续线性规划/LP松弛

#### 做法

- 保留面积、适宜性、产销和线性化收入。
- 暂不加最小种植面积和最大地块数，将启用变量松弛或尽量不使用。
- 对需要0-1选择的水浇地模式可先保留整数变量，因此它也可以视为“简化MILP基线”。

#### 用途

- 验证数据连接、利润核算和销量线性化是否正确。
- 作为完整MILP的利润上界或弱管理基准。

#### 优点

- 求解快，易于检查。
- 能迅速暴露单位、价格解析和销量上限错误。

#### 局限

- 可能把作物切成过多小面积并分散至过多地块。
- 不能作为最终方案。

### 2.2 主模型：多时期混合整数线性规划

#### 做法

在共同模型骨架上加入完整的 `y`、水浇地模式、重茬、三年豆类、最小面积和最大地块数约束，对两种超产政策分别求解。

#### 优点

- 与题意对应最完整。
- 可直接输出官方模板需要的地块级面积。
- 可追溯每项约束对利润的影响。

#### 局限

- 二进制变量数较多，管理阈值过严时可能不可行。
- “不能太分散”的量化参数不是题目已知值，必须做敏感性分析。

### 2.3 备选模型：可行规则构造 + 局部搜索

#### 做法

- 先按单位期望利润、销量缺口和豆类紧迫度生成初始可行解。
- 用交换作物、调整地块、合并零散面积和修复轮作的邻域操作改进。
- 可选模拟退火、禁忌搜索或大邻域搜索。

#### 适用条件

- MILP在限定时间内无法达到可接受的最优间隙。
- 需要快速生成高质量热启动解。

#### 局限

- 不保证全局最优。
- 约束修复必须彻底，否则容易产生表面利润高但不可行的方案。

### 2.4 问题 1 第一轮选择

- 必跑：简化LP/MILP基线 + 完整MILP主模型。
- 备用：只在主模型求解过慢或无可行解时启用启发式。
- 两种超产情景必须共用完全相同的数据和约束，只改变超产收入。

## 3. 问题 2 模型池

### 3.1 基线模型：均值参数 MILP + 独立蒙特卡洛评估

#### 做法

- 用题面区间的中点或平均增长率生成各年确定性参数。
- 使用问题1的完整MILP求一套“均值最优”方案。
- 在不改变种植面积的前提下，用独立抽样情景评估利润分布。

#### 优点

- 实现容易，便于判断“只用平均参数”的方案有多大风险。
- 为随机优化提供比较基准。

#### 局限

- 风险只在事后评估，没有进入种植决策。
- 对于高利润高波动作物可能过度集中。

### 3.2 主模型：基于情景的 SAA-CVaR 随机 MILP

#### 做法

1. 按题面规则生成销量、亩产量、成本和价格情景。
2. 所有情景共享同一套 `x,y,r` 种植决策，每个情景单独计算产量、销量和利润。
3. 以期望利润和损失CVaR建立折中目标。

设情景利润为 `P[ω]`，损失 `L[ω]=-P[ω]`，则：

```text
CVaR_alpha(L) = eta + 1/((1-alpha)*N) * sum(xi[ω])
xi[ω] >= L[ω] - eta
xi[ω] >= 0
```

目标：

```text
maximize E[P] - lambda * CVaR_alpha(L)
```

#### 优点

- 风险直接进入种植决策，能控制不利情景。
- 情景参数和目标仍可线性化，与问题1模型骨架一致。
- 可通过改变 `lambda` 输出风险-收益前沿。

#### 局限

- 场景数与模型规模成比例增长，求解时间可能较长。
- 结果依赖于题面区间到概率分布的假设。

### 3.3 备选模型：预算不确定集的鲁棒 MILP

#### 做法

- 对销量、产量、成本和价格设置区间。
- 用鲁棒预算 `Gamma` 控制多少个参数可同时取不利值，避免所有参数同时最差造成过度保守。

#### 优点

- 不要求精确的概率分布。
- 能给出不利范围内的保障。

#### 局限

- `Gamma` 需人为选择。
- 可能牺牲较多平均利润，经济解释不如CVaR直观。

### 3.4 问题 2 第一轮选择

- 基线：均值参数MILP。
- 主模型：SAA-CVaR随机MILP，`α=0.90`，风险权重运行 `λ in {0, 0.25, 0.50}`。
- 备选：如SAA求解时间过长，先用均值方案 + 蒙特卡洛评估交付第一轮，再尝试鲁棒MILP。

## 4. 问题 3 模型池

### 4.1 基线模型：问题 2 独立情景模型

将问题2已选定的种植方案和风险指标作为对照，不加任何作物间关系或参数相关性。

它不是问题3的最终解，而是回答“加入相关关系后改变了什么”的必要对照组。

### 4.2 控制模型 Q3-A：仅加入参数相关性

保持问题2中每个参数原有的分布和波动范围不变，只改变这些参数“是否一起涨跌”，不加入作物替代或互补关系。Q3-A重新优化种植方案，用于单独回答：参数相关性会怎样改变方案和风险。

### 4.3 最终模型 Q3-B：潜在因子相关情景 + 替代/互补 + SAA-CVaR

#### 相关参数生成

设置三类独立公共因子：

- 市场景气因子 `M`：同时正向影响同类作物的需求和价格；表示市场需求整体变旺时，销量上限和价格可以同时提高。
- 投入品成本因子 `C`：同时推动种植成本，并可部分传导至价格。
- 气候因子 `W`：正向影响同类作物亩产量，并对有随机价格波动的作物价格施加负向影响，用于表达“丰产时价格承压”的谷贱伤农机制。

每个参数变化由“公共因子 + 作物个体扰动”组成。实现时先将合成扰动标准化，再计算标准正态分布函数值 `u=Phi(z)`，最后用目标分布的逆分布函数映射到题面给定的变化区间。这样Q3-A与问题2保持相同的单变量分布和波动范围，只改变联合相关结构。

粮食价格按“基本稳定”解释为围绕年度基准价小幅波动 `Uniform(-1%,1%)`：问题2中该扰动独立，问题3中允许它受气候因子负向影响。羊肚菌价格仍严格按每年下降5%处理，因没有随机价格波动，不参与价格—产量相关关系。

#### 替代和互补效应

设作物 `i`对作物 `j` 的交叉价格弹性为 `epsilon[i,j]`，则可用：

```text
adjusted_demand[i] = base_demand[i] * (1 + sum_j epsilon[i,j] * price_change[j])
```

- 替代品：`epsilon[i,j] > 0`，对方价格上升会提高本作物需求。
- 互补品：`epsilon[i,j] < 0`，对方价格上升会降低本作物需求。
- 调整后需求必须设下界0，并在第一轮限制在基准需求的50%-150%内，避免模拟假设造成极端失真。

将调整后的联合情景输入问题2的SAA-CVaR模型，重新求解种植决策。

#### 优点

- 同时回答题目要求的替代性、互补性和参数相关性。
- 相关数据生成机制可解释，可做弱-中-强情景。
- 与问题2共享优化模型，对比公平。

#### 局限

- 附件不足以从真实数据估计相关系数和弹性，参数属于模拟假设。
- 必须通过多档强度的敏感性证明结论不依赖单一主观参数。

### 4.4 备选模型：作物类群应激情景 + 稳健性检验

如潜在因子和交叉弹性使模型过于复杂，则把作物分为粮食、豆类、叶菜、茄果、根茎/萝卜、食用菌等类群，对每个类群设置共同需求冲击和成本冲击，只运行弱、中、强三档情景。

该模型不如主模型精细，但参数少、计算快，适合做稳健性检验。

### 4.5 问题 3 第一轮选择

- 必须先固定问题2的基准结果和测试情景评价程序。
- 第一轮必须依次求解Q3-A“仅相关”和Q3-B“相关+替代/互补”，不能把替代、互补降为可选扩展。
- Q3-B以小强度交叉价格弹性为主设定，并补跑弹性为0和中强度的单因素敏感性分析。
- 在与问题2相同的 `α`和`λ`下求解，并在同一批相关测试情景下评价问题2方案、Q3-A方案与Q3-B方案。
- 代码必须输出模拟后的实际边际分布统计量和经验相关系数；公共因子权重不直接当作相关系数解释。

## 5. 模型比较指标

### 5.1 所有模型的必查指标

- 最大约束违反值，必须为0或小于数值容差。
- 求解状态、求解时间、目标值、MIP gap。
- 年度利润、七年累计利润。
- 正常销量、超产量、浪费量和超产率。
- 土地利用率和休耕面积。
- 每作物每季使用的地块数、最小实际种植面积。
- 重茬违反数、三年豆类违反数，必须为0。

### 5.2 问题2、3的风险指标

- 样本外平均利润。
- 利润标准差和变异系数。
- 5%分位利润、最差1%平均利润。
- VaR和CVaR。
- 利润低于问题1基准或低于零的概率。
- 超产率、作物面积集中度（HHI）。
- 问题2和问题3方案在同一测试情景下的配对利润差。

## 6. 检验和情景分析设计

| 检验 | 参数/情景 | 需回答的问题 |
|---|---|---|
| 价格口径 | 下界、中点、上界 | 问题1的作物结构是否对价格取值过度敏感 |
| 销量汇总 | 作物-季次 vs 作物-全年 | “每季”口径是否改变主要结论 |
| 土地使用 | 允许休耕 vs 强制满种 | 是否存在负边际利润土地 |
| 最小种植面积 | 露天地/水浇地 {3,5,8}亩，大棚 {0.3,0.6}亩 | 方便管理要求要牺牲多少利润 |
| 最大地块数 | {5,7,9} | 分散度限制是否造成明显收益损失 |
| 三年豆类覆盖 | 累计面积覆盖 vs 整块至少种植一次 | 豆类约束解释是否改变主要方案 |
| SAA场景数 | 50、100、200 | 方案和风险指标是否收敛 |
| 风险权重 | `λ={0,0.25,0.50}` | 收益和尾部风险如何取舍 |
| 相关强度 | 弱、中、强 | 问题3的方向性结论是否稳定 |
| 交叉价格弹性 | 0、小强度、中强度 | 作物替代效应对面积结构影响多大 |

## 7. 可实现性与技术风险

### 7.1 可实现性

- 仅为适宜的地块-季次-作物组合创建变量，可将理论上数万个无效组合大幅删减。
- 问题1的分段收益、地块数、最小面积、轮作和豆类约束都可线性化。
- 问题2的CVaR也可线性化，主要风险是情景数导致模型过大，不是数学上无法求解。

### 7.2 主要技术风险和处理

| 风险 | 表现 | 处理 |
|---|---|---|
| 模型不可行 | 加入管理阈值后无解 | 按“最大地块数-最小面积-豆类面积”顺序查找冲突，不先删农业硬约束 |
| MIP求解慢 | 规定时间内gap较大 | 删除无效组合、用基线解热启动、先用50-100个场景、设时间上限并报告gap |
| 情景过拟合 | 优化情景表现好、样本外测试情景表现差 | 固定独立样本外测试情景集，增加情景数检查方案稳定性 |
| 模拟参数主观 | 问题3结论随相关系数反转 | 弱-中-强三档检验，只将稳定的方向性发现写成结论 |
| 模板填写错位 | 单季写到第二季或行列错配 | 使用显式的年份-季次-地块-作物映射表，导出后做行列总和校验 |

## 8. 第一轮实验总顺序

1. 数据清洗与字段校验。
2. 构造适宜性矩阵、2023年初始状态和基准预期销量。
3. 运行问题1简化基线，通过单位、销量和利润对账后再运行完整MILP。
4. 问题1两种超产情景独立求解、填模板、做可行性检查。
5. 运行问题2均值基线，再运行100个优化情景的SAA-CVaR模型。
6. 用2000个独立测试情景评估问题2候选方案，由乙确认折中解。
7. 在问题2评价程序锁定后，建立问题3弱相关试验，再扩展到中、强相关。
8. 对问题2和问题3方案做同情景配对对比，不使用两套不同测试样本。

## 9. 本步明确结论

> **明确结论：**第一轮不盲目堆模型：问题1用简化线性基线校验后运行完整MILP，问题2以均值MILP为基线、SAA-CVaR随机MILP为主模型，问题3在问题2固定后用潜在因子和交叉价格弹性构造相关情景；所有模型都用约束可行性、样本外利润和尾部风险统一比较。

## 10. 给丙的交接话术

> 模型池已锁定：问题1先跑简化基线，再跑完整MILP的两种超产情景；问题2跑均值MILP和SAA-CVaR三个风险权重，用独立测试情景比较；问题3必须等问题2程序和结果固定后再加入相关因子和替代/互补关系。具体输入、参数、输出表和验收标准见《给代码手的第一轮任务》。
