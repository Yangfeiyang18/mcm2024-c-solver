# 2024 年 C 题特征与变量

> 主责角色：乙（建模手）  
> 目的：说清模型为什么需要每个变量、数据中是否存在、如何从附件加工得到。

## 1. 建模粒度与索引

本题的最小决策单元为“年份-季次-地块-作物”，不能只按作物总面积或地块类型汇总求解，否则无法表达重茬和三年豆类约束。

| 索引 | 含义 | 取值 |
|---|---|---|
| `t` | 年份 | 2024-2030 |
| `l` | 地块 | A1-F4，共54个 |
| `s` | 种植季次 | 单季/第一季/第二季；输出时单季映射至第一季 |
| `c` | 作物 | 1-41 |
| `g` | 地块类型 | 平旱地、梯田、山坡地、水浇地、普通大棚、智慧大棚 |
| `ω` | 不确定性情景 | 问题2、3中的模拟情景 |

## 3. 因变量/目标对象

本题不是常规监督学习，严格来说没有需要拟合的单一“因变量”。对应到优化问题，最终目标对象为：

- 问题1：2024-2030年累计净利润。
- 问题2：期望累计利润和尾部亏损风险。
- 问题3：相关情景下的期望利润、CVaR及与问题2方案的性能差。

## 4. 决策变量和辅助变量

| 符号 | 类型 | 含义 | 为什么需要 |
|---|---|---|---|
| `x[t,l,s,c]` | 连续，非负 | 种植面积/亩 | 核心输出，直接填入结果模板 |
| `y[t,l,s,c]` | 0-1 | 是否在该单元种植作物 | 联系最小面积、地块数和重茬约束 |
| `r[t,l]` | 0-1 | 水浇地当年是否选择单季水稻 | 排除“水稻”与“两季蔬菜”同年并存 |
| `q[t,c,s]` | 连续 | 作物当季总产量 | 连接面积、亩产量和销售上限 |
| `u[t,c,s]` | 连续 | 正常价格销量 | 线性表达 `min(q,D)` |
| `v[t,c,s]` | 连续 | 超出预期销量的产量 | 核算浪费或半价收入 |
| `profit[ω]` | 连续 | 情景 `ω` 下的七年利润 | 问题2、3计算期望、分位数和CVaR |
| `η, ξ[ω]` | 连续 | CVaR线性化变量 | 在模型中直接惩罚尾部损失 |

## 6. 必须加工的衍生特征和参数

### 6.1 基础清洗特征

- `plot_id_clean`：合并单元格造成的空白地块名向下填充。
- `land_type_clean`、`crop_name_clean`、`crop_type_clean`：删除首尾空格。
- `season_std`：统一“单季、第一季、第二季”编码，另保留输出模板行映射。
- `price_low`、`price_high`、`price_mid`：将价格区间字符串拆分为数值。
- `is_legume[c]`：黄豆、黑豆、红豆、绿豆、爬豆、豇豆、刀豆、芸豆标记为1。

### 6.2 结构和可行性特征

- `eligible[l,s,c]`：作物是否允许在该地块和季次种植。不允许的组合不创建变量，以减小模型。
- `previous_crop[l,s,c]`：上一连续种植时段是否种该作物，用于防止重茬。
- `bean_area_2023[l]`：每个地块 2023 年的豆类种植面积，用于 2023-2025 窗口。
- `water_mode[t,l]`：水浇地年度模式，单季水稻或两季蔬菜。
- `max_plot_count[c,s]`：某作物单季允许使用的最大地块数。
- `min_area[l]`：作物一旦进入某地块时的最小种植面积。

### 6.3 产销与经济特征

- `demand_2023[c,s]`：将 2023 年各地块的 `种植面积 × 亩产量` 按作物-季次汇总，作为基准预期销量。
- `unit_margin_2023[c,g,s] = yield * price_mid - cost`：用于排查参数、解释作物选择，不能取代带销量上限的正式利润函数。
- `production[t,c,s]`、`normal_sales[t,c,s]`、`surplus[t,c,s]`：连接种植方案与分段销售收入。
- `land_utilization[t,l,s]`：实际种植面积/可用面积，用于检查休耕和面积错误。
- `fragmentation[c,t,s]`：某作物当季使用的地块数，用于管理性评价。

### 6.4 问题 2 不确定特征

- `demand[t,c,s,ω]`：情景销售量。
- `yield[t,c,g,s,ω]`：情景亩产量。
- `cost[t,c,g,s,ω]`：情景单亩成本。
- `price[t,c,g,s,ω]`：情景销售价格。
- `expected_profit`、`profit_std`、`VaR_5`、`CVaR_5`、`shortfall_probability`：评价方案的收益与尾部风险。

### 6.5 问题 3 相关性特征

- `substitute_group[c]`：替代品组，如小麦-玉米、叶菜类、茄果类等。
- `complement_group[c]`：互补品组，第一轮只做小强度模拟并明确标注假设。
- `cross_price_elasticity[i,j]`：作物 `j` 价格变化对作物 `i` 需求的影响。
- `common_market_factor`、`input_cost_factor`、`climate_factor`：通过潜在因子生成合法的相关情景，避免人工相关矩阵非正定。
- `correlated_profit[ω]`：相关情景下的总利润，用于与问题2统一比较。
- `q3_model_layer`：区分Q3-A“仅相关”和Q3-B“相关+替代/互补”，两层都要正式运行。
- `grain_price_noise`：粮食年度基准价的 `Uniform(-1%,1%)` 小幅扰动；问题2中独立，问题3中可受气候因子负向影响。
- 羊肚菌价格严格按每年下降5%，因没有随机波动，不参与价格—产量相关机制。
- 相关扰动使用 `z -> Phi(z) -> F^{-1}(u)` 映射回问题2边际分布，并保存经验分布与经验相关系数用于审核。

## 7. 不应使用或不能偷看的信息

本题不是传统预测任务，但仍存在信息泄漏风险：

- 不能用未来某一模拟情景的实现值专门为该情景调整种植面积，再将该利润当作事前决策的绩效。
- 问题2、3的测试情景不得参与模型求解、风险权重选择或参数调整。
- 不能把优化后的未来总产量反向定义为未来预期销售量，否则销量上限将失去意义。
- 不能把问题1的最优作物选择当作问题2的强制输入；它只是基准或热启动。
- 不能将模拟设定的相关系数、弹性或风险偏好描述为附件中已观测到的参数。

## 8. 关键数据问题和处理规则

### 8.1 合并单元格造成的空值

2023年种植表中，同一地块有多条作物或两季记录时，后续行的“种植地块”是空白。这是排版导致，不是真实缺失。

**处理：**向下填充地块名后再连接数据，不能直接删除空值行。

### 8.2 文本尾部空格

已发现 `普通大棚 `、`蔬菜 `、`菠菜 `、`生菜 ` 等带尾部空格的值。

**处理：**所有名称、类型和季次字段先 `strip/trim`，再做匹配。

### 8.3 底部说明行

统计数据工作表的使用区域包含底部文字说明，不是所有非空行都是作物参数。

**处理：**只保留“序号和作物编号均为数值”的行，应得到107条有效记录。

### 8.4 智慧大棚第一季参数按附件说明复用

统计参数表没有逐行列出“智慧大棚-第一季”参数，但附件2注释明确规定：智慧大棚第一季可种植的蔬菜及其亩产量、种植成本和销售价格均与普通大棚相同，表中省略。

因此程序直接复用同作物“普通大棚-第一季”参数，并保留 `parameter_source=specified_same_as_ordinary_greenhouse_first_season` 来源标记。该处理属于题面规则，不是缺失值猜测，也不需要作为主观补值单独做敏感性分析。

### 8.5 价格是区间字符串

**处理：**拆分为 `price_low`、`price_high`和`price_mid`。问题1用中点，问题2、3的未来变化基于中点递推，上下界用于敏感性。

## 9. 第一轮关键假设

1. 附件数据能代表2023年的平均生产和市场情况。
2. 作物当季收获、当季销售，不考虑库存跨季或跨年。
3. 同一作物当季预期销售量为各地块总产量共享的市场上限。
4. 问题1的价格取区间中点，2023年预期销量用2023年实际产量估计。
5. 土地面积约束允许休耕；另运行“强制满种”情景检验结论。
6. 三年豆类要求按滚动窗口处理，对每个地块要求任意连续三年的豆类累计种植面积不小于地块面积。
7. 重茬按连续可种时段处理：单季地按年连续，智慧大棚同时检查年内两季和跨年两季。
8. 第一轮管理参数暂设：露天地/水浇地最小种植面积5亩，大棚最小0.3亩；每作物每季最多进入7个地块。必须对最小面积和最大地块数做敏感性分析，不将其写成题目事实。
9. 问题2、3的决策面积为事前方案，所有模拟情景共享同一套种植决策。

## 10. 待乙与丙共同确认的疑点

| 疑点 | 第一轮口径 | 需做的验证 |
|---|---|---|
| 预期销量按作物还是作物-季次汇总 | 按作物-季次 | 与“按作物全年汇总”比较 |
| 三年豆类覆盖口径 | 三年累计豆类面积不少于地块面积 | 至少一个季次整块种植豆类 |
| 土地是否必须满种 | 允许休耕 | 与强制满种比较 |
| 三年豆类是否要求整个地块面积累计覆盖 | 是 | 检查是否造成不可行或过度限制 |
| 管理性参数 | 5亩/0.3亩，最多7块 | 对最小面积{3,5,8}、地块数{5,7,9}做网格检验 |
| 问题2风险偏好 | 同时运行三个风险权重 | 输出风险-收益前沿后由乙选折中解 |

## 11. 本步明确结论

> **明确结论：**模型第一轮可直接使用的原始字段已齐全，核心决策变量是 `x[t,l,s,c]`；必须先完成合并单元格向下填充、文本清洗、价格区间拆分、按附件说明复用智慧大棚第一季参数和2023年预期销量推算，才能建立可求解的模型。
